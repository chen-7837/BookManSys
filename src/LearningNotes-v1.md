## v1.0 的核心逻辑

```
Book 类
  │
  ├── 定义书籍的属性与行为
  │
  ▼
创建多个 Book 对象
  │
  ▼
ArrayList<Book> 统一保存
  │
  ▼
循环遍历集合
  │
  ▼
调用每本书的 showInfo()
  │
  ▼
展示书籍信息
```

## v1.0 → v2.0：知识如何递进？

v1.0：建立基础

类、对象、封装、构造方法、ArrayList、循环、Git。

v2.0：组织复杂关系

继承、多态、抽象类、接口、借阅状态、Library 业务管理。

这两版最重要的区别： v1.0 主要解决“如何描述一本书、保存多本书”；v2.0 则进一步解决“不同类型的书如何统一管理，又各自执行不同的行为”。
